# What Is an XM Partner Code?

An XM Partner Code is a referral identifier entered while opening a new XM trading account.

When you register through a qualifying partner campaign, the code connects your account with that campaign. Depending on your country of residence, the regulatory entity serving your account, and XM's current promotional terms, you may become eligible for certain promotional offers.

The partner code field appears **only during registration**.

Once the registration form has been submitted, this field is generally locked permanently.

That means if you intend to register using the partner code **7WCMC**, you should enter it before completing your application.
